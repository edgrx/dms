Your patient database and attachment folder will belong to your clinic's Google account. This setup creates new, dedicated files; it does not import existing patient data.

Use the clinic's Google account. Google will ask for authorization; DMS does not ask for your Google password. OAuth access tokens stay in this browser's memory and are not sent to DMS.

Manual setup / resume existing setup

Already created your dedicated files? Enter their IDs below. For Client-Owned API you may also enter the existing deployment URL and restricted management credential. Do not create duplicate resources.

1. Create private storage

Creates a blank spreadsheet and empty attachment folder using your Google account. If creation is interrupted, check your Google Drive before repeating.

Open spreadsheetOpen folder

Grant Central API access

Only the designated DMS account receives Editor access. Your Google files remain Restricted. You can revoke access later, but this clinic's Central API will stop working.

2. Install private Client API

Enable Google Apps Script API access in your account settings (one-time), then return to this page.

Open Apps Script settings
Open script editor

The first run must be authorized by the clinic owner. In the script editor (use Desktop site on mobile if needed), choose quickSetupClient → Run → review and allow Google permissions. The function creates the database tables and a pending unpaid Admin account. Wait for Execution completed. If Sheets API is disabled for this script, enable it in Services / Google Cloud as prompted.

3. Create deployments

After the first run completes, create the public API. Automatic deployment is experimental; use the manual instructions if Google refuses it.

Manual deployment and private owner dashboard
  1. In the script editor: Deploy → New deployment → Web app. Execute as Me (your clinic Google account), access Anyone. Copy the public URL ending in /exec. If already deployed automatically, do not create another public deployment.
  2. Create a separate private deployment: Execute as Me, access Only myself. Open its URL with ?owner=1 appended.
  3. In the private dashboard: Register → Generate / rotate management credential. Copy only that credential, not the clinical login key.

No permanent developer access to Google Sheets or Drive is needed. Management access is restricted to account operations and health checks by the existing DMS backend.

Setup submitted

Your DMS provider will verify the connection and activate your purchased account. For a private API, the clinic owner issues the login key after activation. No patient records have been submitted by this wizard.
